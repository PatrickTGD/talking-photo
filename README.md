# Talking Photo — free on Google Colab

Make one photo speak, using SadTalker on a free cloud GPU.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/PatrickTGD/talking-photo/blob/main/talking-photo.ipynb)

1. Tap the badge above.
2. Menu: Runtime → Change runtime type → T4 GPU → Save.
3. Press the play button on each box, top to bottom.
4. In step 4, upload one clear face photo.
5. In step 5, watch your talking photo and download the video.

`voice.mp3` is the sample voice Moss made. You can replace it with any short voice recording.
